## Required sections
1. Short answer: what problem the module solves
2. Who uses this module and typical tasks
3. Supported workflows: before → action → result
4. Feature list, each with a source and a verified state
5. Limits and dependencies (plan, permissions, internet, external integrations)
6. Real product screenshot/video (approved, no guest PII)
7. English and Bangla FAQs grounded in operators' actual questions
8. Related modules and how they hand off data (only verified connections)
9. Real CTA (demo, speak to product team)
10. SEO markup: canonical, hreflang pairing, breadcrumbs and relevant structured data
