# Buyer Segmentation — Property Type ≠ Accommodation Type

## Property type: business-level classification
| Proposed property segment | Operating need | Main modules | SEO intent |
|---|---|---|---|
| Hotel | Reception, room inventory, arrivals/departures | Reservations, Rooms, Front Desk | hotel management software |
| Resort | Multiple stay categories, services, restaurant and experiences | HMS, Services, Restaurant, QR | resort management software |
| Boutique hotel / guesthouse | Small teams and direct bookings | Reservations, Website, Staff | small hotel software |
| Hotel group | Multiple properties, permission boundaries | Business Account, Reporting | multi property hotel software |
| Serviced accommodation / apartments | Unit availability and stay lifecycle | Accommodation, Guest, Finance | serviced apartment management |
| Cottage / villa operator | Distinct unit categories and amenities | Accommodation, Booking, Services | villa / cottage booking system |

These are **content audiences**, not proof all are supported commercially.

## Accommodation type: sellable inventory class (internal V1 plan)
1. Room
2. Cottage
3. Villa
4. Apartment
5. Dormitory
6. Other / Custom

Suite, Deluxe, Twin, Double describe category/configuration rather than universal independent accommodation types. For dormitories, per-bed availability can differ from whole-room inventory; engineering must confirm implementation before SEO claims.

## Parent-child navigation approach
```text
Solutions
  Hotels → module links
  Resorts → modules + services examples
  Hotel Groups → verified multi-property scope
  Smaller Properties → appropriate plan + setup guide
Accommodation Topics (supporting guides)
  Rooms / Cottages / Villas / Apartments / Dormitories
```
Do not generate hundreds of “{city} {property-type} software” duplicates with no original local evidence.

## Content differentiation examples
**Hotel page:** Arrival/check-in speed, booking source clarity, room status, staff permissions and reporting.  
**Resort page:** Mixed accommodation, service operations, on-property dining, long-stay guest service and housekeeping coordination.  
**Group page:** Property context switching, group-wide view, entity boundaries and consolidated reporting only if verified.
