# Archived Versions

This folder is reserved for **deliberately archived older versions** of BinGi SEO plans, screenshots, content drafts and guides.

Suggested structure:
```text
ARCHIVE/
  2026-11-09/
    ORIGINAL-CONTENT/
    archive-manifest.md
  2026-xx-xx/
    ...
```

There were no legacy SEO documents in this repository when this new project started, so **nothing has been moved or removed**.

Git history is the canonical revision record. When moving any future file into this archive, preserve its path/source commit, mark the archived snapshot superseded and link to the current replacement.
