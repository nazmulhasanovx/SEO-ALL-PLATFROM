# BinGi SEO — First 90 Days (proposed)
**Started 2026-11-09.** This is a plan, not a claim that deployment/tasks are scheduled or completed.

| Period | Deliverables | Done when |
|---|---|---|
| Days 1–15 | Baseline discovery; crawl/index/sitemap/robots/redirect audit; approved brand facts | Evidence-backed issue register; GSC/Bing access verified |
| Days 16–35 | P1 module content briefs and prioritized EN+BN drafts | Product-approved facts, original visuals, approved publication tickets |
| Days 36–60 | Solutions pages, how-to docs and useful supporting guides | Editorial reviews complete; published links inspected |
| Days 61–90 | Accurate structured data, earned distribution, video tutorials, AI-answer sampling and refinements | Search measurement dashboard; QA and change log updated |

## Operating cadence
- Weekly: one coherent content cluster reviewed and approved; measure actual throughput before committing volume.
- Biweekly: technical issues and index coverage review.
- Monthly: Bing + Google organic queries, assisted conversions, EN/BN coverage, cited AI answers accuracy and freshness.

## Minimum sign-off before technical deployment
1. Domain and DNS/Web server/website release owner assigned.
2. Existing URL inventory and redirect plan captured.
3. Analytics permission and conversion definitions confirmed.
4. Current module availability and pricing matrix approved.
5. Owner authorizes published changes.

## Category handoff
After Category 01 review, execute Category 02 technical audit. Create one versioned category commit at a time to preserve inspectability.
