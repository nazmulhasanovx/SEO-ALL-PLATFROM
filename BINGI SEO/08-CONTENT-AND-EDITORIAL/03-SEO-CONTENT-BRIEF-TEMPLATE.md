# Content Brief — Reusable Template

## Metadata
- ID / owner / editor / review deadline:
- Existing or proposed URL:
- Language / locale / market:
- Persona / decision stage:
- Search query cluster:
- Current top search results reviewed (with date):
- Search intent and unique value offered:
- Source evidence with feature status (live/pilot/planned):
- Related official module and solution pages:
- CTA and conversion event:

## Draft outline
1. H1: benefit explained without unverified superlatives.
2. Direct 50–90 word answer to user's key question.
3. Relevant problem or scenario (verified and realistic).
4. Product-specific process/screenshots, if actually released.
5. Feature + limitation table.
6. Comparison or checklist that is useful even without purchasing.
7. Relevant operator FAQs (natural language).
8. Helpful internal links and next action.

## Technical checklist
- Unique SEO title and description.
- Self-canonical and correct final live URL.
- Hreflang only to approved published equivalents.
- Visuals anonymized and compressed; alt text meaningful.
- Structured data reflects visible content and Google eligibility.
- Mobile and keyboard accessible.
- Actual deployed page inspected before marking published.
