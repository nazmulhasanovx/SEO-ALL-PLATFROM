# Public Property Page — Data, Trust & Editorial Requirements

## Minimum quality dataset for each verified listing
- Verified property name and location;
- Property type and accommodation choices actually sellable;
- Authentic photos with rights and relevant alt text;
- Accurate amenities, check-in/out rules and property policies;
- Publicly shareable contact and location details;
- Pricing/tax/fee description that is consistent with live checkout;
- Current rate and availability signals only when connected to real inventory;
- Genuine review evidence and stated provenance, if displayed;
- Clear booking cancellation/refund rules appropriate to the property.

## Listing statuses
- **LIVE VERIFIED:** identity and contact validated, live inventory permitted.
- **DEMO / TEST:** excluded from public search production inventory and rich content, clearly labeled when shown internally.
- **PENDING:** not presented as a confirmed operating property.
- **INACTIVE:** removed from search discovery or redirected according to documented lifecycle.

## Structured data
Potential hospitality/lodging schema only when it exactly matches visible real property information. Do not invent ratings, prices or geographic coordinates. Follow search-engine guidelines on eligible rich-result types.

## Media and privacy
Never expose guest personal information, staff data, booking references, user-provided private media or payment details. Use licensed property photography and permissioned reviews.

## Owner handoff
A verified listing should contain a last-updated timestamp and authorized property manager responsible for content accuracy.
