# Destination Pages, Search Filters & Crawl Budget

## Destination pages
Only create a destination landing page when it delivers genuine traveler value: real listed properties, specific location knowledge, practical transportation context, distinct property categories and useful guidance. Avoid thin city-template doorway pages.

## Faceted filtering
Filter combinations for guest count, dates, room types, amenities, sort direction and price should not create uncontrolled indexable URL explosions.

Technical options depend on the website:
- Keep public canonical destination/property URLs clear.
- For filter permutations without unique search value, manage indexing and canonical strategy deliberately.
- Ensure pagination/load-more gives crawlers useful stable URLs where appropriate.
- Never put live personalized availability/checkout data in search index.

## Review checklist
- [ ] Destination has enough real, verified listings and useful original details.
- [ ] No duplicate variant pages for spelling aliases without clear canonical.
- [ ] Accurate public location and policy details.
- [ ] Current property visibility status.
