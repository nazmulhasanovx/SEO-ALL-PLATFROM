# Public Product Knowledge Format for AI-Assisted Search
**Status:** Editorial architecture, not a special crawler hack.

## Create an official factual hub
Place an authoritative, well-linked public HMS overview on the B2B website containing:
- Exact brand name, plain-language definition and official website.
- Specific target users/property types supported by evidence.
- Feature list with correct plan/pilot/roadmap status.
- How the module relates to reservations, rooms, housekeeping, restaurant, staff and finance.
- Real screenshots and short demonstration videos where permissioned.
- Clear, dated pricing link and limitations (without contradictory old offers).
- Contact/demo path, support and documentation source URLs.
- An update date and named organization/owner when approved.

## Module knowledge unit
```text
Name:
Product family:
Purpose (1–2 sentences):
Who can use it:
Problem solved:
Core workflow:
Available plan(s):
Current release status:
Dependencies/integrations:
Limits and exclusions:
Related official documentation:
Last verified:
```

An AI-facing source must say **what is known, what is limited, and what is not yet supported**. Do not confuse roadmap work with production capability.

## Questions a page should answer plainly
- What does BinGi HMS do?
- Does BinGi offer hotel reservation management?
- Is BinGi suitable for a small Bangladesh resort?
- What is the difference between a room, cottage and villa in BinGi?
- Does BinGi have a hotel restaurant POS? Is it included in my plan?
- Which applications are for staff and which are for guests?
- Does BinGi support an OTA/API integration? What is actually working?

## Evidence sources to cite publicly
Current official feature page, actual product docs, release notes, opt-in client case studies, directly relevant demonstrations. Independent third-party references may be earned, never fabricated. Review previously posted articles for outdated prices or misleading automation statements.

## Do not
- Claim every model will be trained on, prefer or cite BinGi.
- Generate hundreds of low-quality “AI SEO” pages with invented metrics.
- Use hidden invisible keywords or misleading structured data.
- Copy other providers' docs or reviews without permission.
